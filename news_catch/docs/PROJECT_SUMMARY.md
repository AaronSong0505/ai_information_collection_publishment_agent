# News Catch 项目总结

## 项目概述

News Catch 是基于 NewsNow 开源项目构建的新闻抓取系统，专注于实时新闻抓取、本地存储和为后续 AI 分析做准备。

## 核心功能实现

### ✅ 已实现功能

1. **多源新闻抓取**
   - RSS 源支持
   - HTML 网页解析
   - API 接口抓取
   - 智能内容提取

2. **数据存储系统**
   - SQLite 本地数据库
   - 文章结构化存储
   - 图片自动下载和存储
   - 智能去重机制

3. **任务调度系统**
   - 可配置的定时抓取
   - 并发控制和错误处理
   - 任务状态监控
   - 自动重试机制

4. **缓存机制**
   - 30分钟默认缓存
   - 智能缓存失效
   - 减少重复请求
   - 提高系统性能

5. **API 接口**
   - RESTful API 设计
   - 新闻源管理
   - 文章搜索和查询
   - 爬虫控制接口

6. **监控和日志**
   - 结构化日志系统
   - 抓取状态监控
   - 错误追踪和报告
   - 性能指标记录

## 技术架构

### 后端技术栈
- **运行时**: Node.js 18+
- **数据库**: SQLite (db0)
- **HTTP 框架**: H3
- **HTML 解析**: Cheerio
- **RSS 解析**: fast-xml-parser
- **HTTP 客户端**: ofetch
- **日志系统**: consola

### 项目结构
```
news_catch/
├── server/           # 服务器端核心代码
│   ├── api/         # REST API 路由
│   ├── crawler/     # 爬虫引擎和解析器
│   ├── database/    # 数据库操作层
│   ├── scheduler/   # 任务调度系统
│   ├── sources/     # 新闻源实现
│   └── utils/       # 工具函数
├── shared/          # 共享类型定义
├── scripts/         # 构建和初始化脚本
├── test/           # 测试文件
└── data/           # 数据存储目录
```

## 核心组件

### 1. 爬虫引擎 (CrawlerEngine)
- 支持多种数据源类型
- 智能内容解析
- 图片处理和存储
- 错误处理和重试

### 2. 任务调度器 (TaskScheduler)
- 定时任务管理
- 并发控制
- 状态监控
- 动态配置更新

### 3. 数据存储层
- **ArticleStorage**: 文章数据管理
- **SourceStorage**: 新闻源配置管理
- **Cache**: 缓存系统
- **ImageHandler**: 图片处理

### 4. 内容解析器 (ContentParser)
- HTML 内容解析
- RSS 数据处理
- API 响应解析
- 结构化数据提取

## 数据模型

### 文章数据 (articles)
- 基本信息：标题、内容、摘要
- 时间信息：发布时间、抓取时间
- 来源信息：作者、来源、URL
- 扩展信息：图片、标签、元数据
- 去重标识：内容哈希值

### 新闻源配置 (news_sources)
- 基本配置：名称、URL、类型
- 抓取配置：间隔、选择器、请求头
- 状态信息：启用状态、错误计数
- 时间戳：创建时间、更新时间

### 图片数据 (images)
- 原始信息：原始URL、格式、大小
- 本地信息：本地路径、尺寸
- 关联信息：所属文章ID

## 使用指南

### 快速启动
```bash
# 1. 安装依赖
pnpm install

# 2. 初始化数据库和默认源
pnpm run init-sources

# 3. 运行演示
pnpm run demo

# 4. 启动开发服务器
pnpm run dev
```

### API 使用示例
```bash
# 查看所有新闻源
curl http://localhost:3000/api/sources

# 启动爬虫
curl -X POST http://localhost:3000/api/crawl \
  -H "Content-Type: application/json" \
  -d '{"action": "start"}'

# 搜索文章
curl "http://localhost:3000/api/articles?keyword=news&limit=10"
```

### Docker 部署
```bash
# 构建和运行
pnpm run docker:build
pnpm run docker:run
```
